# Indigenous Earthworks of Eastern North America

A digital humanities project about earthworks built by Indigenous communities in the North and Southeastern United States, from the Archaic to the Mississippian period.

**Live site:** https://chall2007.github.io/my-first-site/

## Pages

- `index.html` is the project home page. It has the embedded StoryMap, an interactive map and timeline of eight earthwork sites, a section on the "Mound Builder" myth, and sources.
- `DH_PROJECT.html` shows the StoryMap full screen.

## Built with

- [StoryMapJS](https://storymap.knightlab.com/) (Northwestern University Knight Lab)
- [Leaflet](https://leafletjs.com/) with OpenStreetMap tiles
- GitHub Pages
